Install in Gmail (once per account)

  1. Open Gmail signed in as that address → click ⚙ (top right) → See all settings.
  2. On the General tab, scroll to Signature → Create new → name it "Business Link".
  3. Click in the signature box and paste (Ctrl+V). Delete any old signature text.
  4. Under Signature defaults, pick it for both For new emails use and On reply/forward use.
  5. Scroll to the bottom → Save Changes. Send yourself a test email to check it.
